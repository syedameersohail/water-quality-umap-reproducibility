# Manuscript → code map

Every reported analysis traced to the script that generates it, its inputs, its
outputs, and the governing configuration. Stage numbers refer to `scripts/`.
Config keys are dotted paths into `config/analysis_config.yaml`.

Legend for status:
- **reproduced** — regenerated by this package's scripts and checked against the
  established outputs during assembly.
- **runnable** — script provided and import/smoke-tested; full run is the user's
  (expensive, or needs the raw download).

## Notes on scientific discipline

- **Portfolio view vs exact retrieval.** The UMAP embedding is a 2-D *portfolio
  visualisation*. Exact peer retrieval is performed in the standardised
  **12-dimensional** space; the hybrid method uses UMAP only to shortlist, then
  re-ranks by 12-D chemical distance.
- **Eligibility before imputation.** Sites are filtered for completeness
  (≥ 9 of 12 observed) *before* any median imputation; medians and the scaler are
  fit on the eligible population only.
- **Same-environment principle.** Robustness/sensitivity embeddings are compared
  only against a reference fitted in the same run/environment; coordinates are
  never compared across package versions.
- **Signatures are cross-sectional.** They summarise typical site chemistry
  (long-term medians), not temporal trends.
